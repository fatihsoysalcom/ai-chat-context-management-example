# AI Chat Context Management Example

This example demonstrates how an AI chat system can maintain conversational context across multiple turns. It simulates a simple AI that uses previous messages to generate more relevant and personalized responses, illustrating the core concept of context management discussed in the article.

## Language

`python`

## How to Run

1. Save the code as `main.py`.
2. Run from your terminal: `python main.py`
3. Type your messages and press Enter.
